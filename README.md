# Cheng Tang's Academic Homepage

Personal academic homepage for Cheng Tang (唐城), a graduate student in
Artificial Intelligence at Xiamen University.

Website: https://vanillatc.github.io/

## Contents

- `index.html`: public profile, education, projects, and contact information
- `styles.css`: responsive layout and print styles
- `script.js`: English/Chinese language switch and email copy button
- `assets/`: GitHub avatar and locally hosted Lucide icons

This is a static website. Open `index.html` in a browser to preview it.
GitHub Pages publishes the root of the `main` branch.

The project descriptions are summaries of the owner's project experience,
not a publication list. The site contains no unpublished research repository,
analytics, credentials, or private project data.
